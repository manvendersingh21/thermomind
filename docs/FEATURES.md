# Feature catalogue

One row per feature. "Wiring" reflects `apps/web/src/App.tsx` at the time of writing: routes present there are live; features whose page or router code exists but has no route are marked **wiring pending**. Provenance labels: real (UCI measurements), model-derived, synthetic (labelled overlay), simulated (physics/connector simulation), assumption (user-editable input). Nothing here writes to a plant system: there is no control write path.

Meta calls use Muse Spark (`muse-spark-1.3`, OpenAI-compatible). Reasoning tokens count against `max_tokens`. Without `MODEL_API_KEY` every Meta-using feature falls back to a deterministic, clearly labelled offline output.
